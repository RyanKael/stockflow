## Descrição para LinkedIn

Desenvolvi o StockFlow, um sistema web para gestão de estoque criado com Python e Flask.

O projeto inclui autenticação de usuários, controle de permissões, cadastro de produtos e categorias, entradas, saídas e ajustes de estoque, inventário físico, auditoria das operações, relatórios em PDF e testes automatizados.


## Como apresentar em uma entrevista

O StockFlow é um sistema de gestão de estoque que desenvolvi com Python e Flask.

A ideia do projeto foi construir uma aplicação completa, indo além de um CRUD simples. Por isso, implementei autenticação, níveis de permissão, movimentações de entrada e saída, inventário físico, auditoria, relatórios em PDF e testes automatizados.

Também preparei o projeto para produção com PostgreSQL, Gunicorn e Railway, além de configurar GitHub Actions para executar os testes automaticamente a cada alteração enviada ao repositório.

Durante o desenvolvimento, trabalhei com regras de negócio, migrations, segurança, tratamento de erros, organização por módulos e deploy em produção.
